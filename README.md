## What usability problems did other students identify?
When testing the design with other students, some had a slight confusion when it was a certain player's turn, either 
just knowing whose turn it was currently or what was the controls available to them. Some also had some struggle when
trying to read some of the assets due to their size. One issue brought up one student was the window size and how some
screen might not be able to fit the original default size screen.
