## What usability problems did other students identify?
When testing the design with other students, some had a slight confusion when it was a certain player's turn, either 
just knowing whose turn it was currently or what was the controls available to them. Some also had some struggle when
trying to read some of the assets due to their size. One issue brought up one student was the window size and how some
screen might not be able to fit the original default size screen.

## Which wireframe revisions most improved the user experience?
The revisions to the clarity of the available actions for a player most improved the user experience. This added
distinction of whose cards and the controls that a user is able to be press, make the user less overwhelmed trying to
navigate the screen for what to do next. The added "hint" text, dimmed controls, and highlighted cards helps give a
player a sense of direction without it being overly 'handholding'.

## How do the animations help users understand game events?
The animations help users understand game events by adding flair to important game details that matter in the current 
stage. These slight animations guides users' focus. By drawing their focus onto these items, the users can first process
the most important details in a given event and their purpose, thus guiding their comprehension of the game state.
